# Original project-owned content

Only content created for this project or clearly licensed for redistribution belongs here. Commercial game assets and private owner data must remain outside the repository.

- `tracks/test-circuit.prtrack`: the minimal text circuit.
- Generated demo tracks (Coastline Run, Pine Ridge, Red Mesa, Night Harbour): CC0-1.0 RCP packs produced deterministically by `crates/trackgen` from their specs, so no binary pack files are stored here. See `docs/TRACKGEN.md`; export them with `cargo run -p racer-trackgen -- all <dir> --pack`.
## cars/

Four low-poly demo cars (Quill Coupe, Brisk Roadster, Tumble Rally, Shard GT) as an RCP v1 pack plus glTF 2.0 exports
(`gltf/*.gltf`, wheels as separate nodes, colour variants via `KHR_materials_variants`). Everything is generated by code
(`cargo run -p racer-cargen`, check with `-- --check`); do not edit by hand. Apache-2.0, no external models or textures.
