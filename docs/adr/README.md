# Architecture Decision Records

Record significant architecture decisions as `NNNN-short-title.md`, using a monotonically increasing number. Keep each record concise and include:

- **Status:** proposed, accepted, superseded, or rejected;
- **Context:** the decision and constraints;
- **Decision:** what was chosen;
- **Consequences:** tradeoffs and follow-up work;
- **Evidence:** relevant implementation or verification.

Do not use ADRs to bypass the project's licensing and content rules.
